# Benchmarking machine learning for multimodal EEG-fNIRS classification of Alzheimer's disease and MCI

Code, per-fold results and figures for the paper
*Benchmarking Machine Learning for Multimodal EEG-fNIRS Classification of Alzheimer's Disease and Mild Cognitive Impairment*
(W. Zhang, H. Zeng, Z. Cai; ICIMH 2026, under revision).

## What is here

| Path | Content |
|---|---|
| `nested_cv_v2.py` | Complete analysis script: nested (inner 3-fold) + 5×5 repeated stratified CV, 12 pipelines, modality comparison, feature-importance stability, modality-block permutation, paired tests |
| `results/` | Per-fold results (`per_fold_*.csv`), summary tables (`table1`–`table4_*.csv`), paired tests (`stats_paired_tests.csv`), importance analyses (`importance_*.csv`, `importance_per_fold.jsonl`), run log with library versions and hyperparameter grids (`run_log.txt`), and the figures as generated by the script |
| `figures/` | Print versions of Figs. 1–5 used in the manuscript (300 dpi) |
| `DATA_PROVENANCE.txt` | Exact dataset file, repository commit and SHA-256 used |
| `requirements.txt` | Python package versions used |

## Reproducing the results

```bash
pip install -r requirements.txt
DATA_PATH=/path/to/5secEEGPSD_FullFnirsPSD_FullFnirsTimeDomain.csv OUT_DIR=./results_repro python nested_cv_v2.py
```

The run takes about 100 minutes on one CPU core and is resumable (completed folds are skipped on restart).
All random seeds are fixed to 42. `QUICK=1` runs a 10-minute smoke test with reduced grids.

## Design summary

* Outer loop: stratified 5-fold CV × 5 repeats (25 test folds), identical folds for every pipeline → paired comparisons.
* Inner loop: stratified 3-fold CV selects the number of features k and all classifier hyperparameters by macro AUC.
* Standardisation and feature ranking are refitted inside every inner and outer training fold.
* Metrics per outer fold; mean, SD and 95% t-interval reported.
* Paired tests: Wilcoxon signed-rank and Nadeau–Bengio corrected resampled t-test, Holm-adjusted per family.
